### In a Nutshell
My config is a hybrid and slightly reduced version of Zabooby's and Ujjwal-dev23's

### Important
As of Sep 19 2026, this config is now solely for the use on linux. I am just so done with windows quirks on specifically my device which is LOQ 15ARP9 (RTX 4050, no iGPU). Kindly tinker with mpv.conf yourself if the config doesn't provide you optimal playback, each device can have its own differences.

### In case you didn't read the docs
Clone this repo rename portable_config to mpv and move the folder mpv to .config/
